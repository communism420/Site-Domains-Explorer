How the extension handles browsing data

Review the details below before enabling automatic domain collection.

01

Data that is processed

Hostnames from opened pages, resource URLs and links, plus the visit time and visit count.

02

Data that is not saved

Page content, full URLs, query strings, cookies, credentials, form values and request bodies are not saved.

03

Local-only storage

Saved data stays in local browser storage on this device. The extension has no analytics and sends no data to a server.

04

Fully open source

All extension code and build files are public under the MIT License. View source code

Permission disclosure

To identify own and third-party services, Site Domains Explorer reads the addresses of websites you open and their network requests, extracts only hostnames, and stores those hostnames locally. This browsing activity is not shared, sold or transmitted off your device.

Domain collection is enabled

You can disable future collection at any time. Existing history remains available until you delete it.
